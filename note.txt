                               FORMS IN HTML

         @> A FORM is basically a collection of input fields where users type stuff , click stuff , choose stuff - and then it gets sent somewhere✈️                      

                LIKE :  [login form , signup form , feedback form , payment , search bar] 


         🏛️ The <form> Tag - this is the container that holds everything 

         {
          <form action="/submit" method="POST">
               <!-- form content here -->
          </form>

           
            @> KEY ATTRIBUTES -> 

                # action = "" - where the data should go (backend URL)


                # method = "" - how the data is sent 
                     
                        * "GET"  - data visible in URL
                        * "POST" - data hidden from URL (safer)               
          ]

                      🐦‍🔥 DIFFERENCE  BETWEEN >>>DIV | SPAN<<<

          @) <span> 

               * inline element

               * doesn't start on a new line 

               * used to style small parts of text

               * can't contain block elements {should NOT put <h1>,<p>,<div> inside} 

          <span> inline container to group elements for styling purposes</span>     

              <h1>
                <span style="background-color: red">THis is sapn title </span>
              </h1>    

......................................................................................

          @) <div>           


             ❌ <div> inside <h1> - wrong move - 💀 
              

              <h1>
                  <div style="background-color: aqua;">this is div title</div>
              </h1>

               |_This is invalid HTML 


        => REASON - <div> is a block-level element

              * A block element cannot live inside a haeding tag(h1,h2,etc...)

              * Browser will auto-fix it by breaking the structure(so it won't behave how you expect)        


            💯 Correct Way to Use DIV  

        => if you wanna style a title with a <div> , you do it like this -

           OPTION 1 - keep div OUTSIDE the heading 

                      [

              <div style="background-color: aqua;">
                  <h1>this is div title</h1>
              </div>

                      ]    


           OPTION 2 - style the heading directly-(Easier, cleaner) 

                      [

              <h1 style="background-color: aqua;">this is div title</h1>


                      ]             


......................................................................................

  
                                🧠 QUICK SUMMARY


                  <SPAN> - 

                   # Inline 

                   # For text-level styling

                   # okay inside heading 

                   # NOT for big layout blocks


                 <DIV> - 

                   # Block    

                   # For layout + big sections 

                   # Should NOT be inside <h1>

                   # Wraps larger areas , not small  words
